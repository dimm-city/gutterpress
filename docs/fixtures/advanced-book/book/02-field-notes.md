# Field Notes

Every warden keeps a field book. The habits below are the difference
between a note you can act on in November and a smudge you argue about
in committee.

@sidebar .gear "Kit check"

**Carry at all times:**

* graphite pencil (ink freezes)
* the district card, laminated
* one spare button compass

![The warden's hitch](assets/knot.svg)

@end-sidebar

## Writing a usable entry

Date every entry twice: once at the top, once inside the text. Pages
tear. A loose page with an internal date can be refiled; a loose page
without one becomes fiction. Keep observations and interpretation in
separate sentences — *the print was four inches long* is observation,
*a large male passed at dawn* is interpretation, and only one of them
survives cross-examination.

@callout note "Cross-reference"

Measurements for common tracks are tabulated with the
[specimen plates](#ch-specimens){.xref}, so field entries need only the
anomalies.

| Reading | Record as |
| --- | --- |
| length | toe to heel, no claws |
| depth | at the pad, in soft ground only |

@end-callout

## Weather discipline

Wind before precipitation, always: a squall that arrives *with* the
wind was visible an hour earlier to anyone watching the ridge. Note the
cloud deck in eighths, and if you cannot see the deck, write that down
too — `deck obscured` is a real observation.

> The book is not a diary. The book is testimony you happen to write
> before anyone has asked the question.

@callout warning "Do not"

Never recopy a field book to make it neater. The original **is** the
record; a fair copy is a second document with a second set of errors.

@end-callout
