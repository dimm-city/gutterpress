# Archive Notes

This file deliberately uses constructs the rich editor refuses — a
footnote and a link-reference definition — so the fixture proves the
fail-closed path: it must open in SOURCE mode with the reason stated,
and the normalize command must refuse it rather than rewrite it.[^1]

The archive index lives at the [district office][archive].

[^1]: Footnotes have no node in the editor's document model, by design.

[archive]: https://example.org/archive
