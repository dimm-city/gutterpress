# Core Full Bleed

The manifest sets this book's margins. Core's `@page full-bleed` page and a
`.gp-bleed` image keep their zero margins under them: the next page's text
starts a quarter inch from the sheet's corner, and the image after it spans
the sheet from edge to edge.
