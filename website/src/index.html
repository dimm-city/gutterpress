Markdown & CSS, typeset for print

Write a book in Markdown. Lay it out with CSS. Export a print-ready PDF.

Gutterpress turns a folder of markdown files into a professionally typeset PDF: the kind you send to an offset printer or a print-on-demand service. It uses a native Chromium print engine and the W3C CSS Paged Media spec, so page breaks, running headers, columns, page numbers, and bleed are handled for you.

Your first book

Three steps, no configuration

  1. Make a folder

    A couple of markdown files is enough.

    my-book/
├─ chapter-01.md
└─ chapter-02.md

  2. Open it in Gutterpress

    Click Open Folder. A paginated preview updates live as you edit.

  3. Save PDF

    Done. Ready for a printer, a print-on-demand service, or publishing straight to Google Drive.

What it does

Print production, from a text editor

  • Live preview with paginated layout: your book renders the way it will print, while you edit.
  • PDF export from the app, or from the gutterpress CLI in scripts and CI.
  • Print-ready output: PDF/X with CMYK and an ICC profile for offset printers, PDF/A for archives.
  • Custom CSS for everything: typography, page size, margins, columns, running headers and footers, page numbers, bleed.
  • Plugins for custom markdown: use any of hundreds of markdown-it plugins, or write your own.
  • Validation before and after a build: image DPI, color space, font embedding, structural PDF checks.
  • Publishing to itch.io, DriveThruRPG, Amazon KDP, Azure Static Web Apps, Shopify, and Google Drive.
Desktop app

Self-contained, nothing else to install

Every download is on the latest release, with SHA-256 checksums. The app bundles its own Chromium; no Node, Bun, or browser setup is needed.

PlatformFileNotes
WindowsGutterpress-setup-win-x64.exeInstaller. The versioned .zip is a portable extract-and-run copy.
macOS, Apple SiliconGutterpress-<version>-arm64.dmgOpen the disk image, drag the app to Applications.
macOS, IntelGutterpress-<version>-x64.dmgSame as above.

The downloads are unsigned for now. Each release includes Gatekeeper and SmartScreen instructions; see installing and verifying.

Command line

The same engine, for scripts and CI

Homebrew (macOS and Linux)

brew tap dimm-city/gutterpress https://github.com/dimm-city/gutterpress.git
brew install dimm-city/gutterpress/gutterpress

Scoop (Windows)

scoop bucket add gutterpress https://github.com/dimm-city/gutterpress.git
scoop install gutterpress/gutterpress

npm

npm install -g gutterpress

Node.js 22 or newer.

Standalone binaries and Docker

Single-file binaries for Linux, macOS, and Windows are on every release, and a Docker image ships with all the print tools preinstalled.

The CLI renders PDFs through a Chromium-based browser on the machine it runs on; some PDF/X and validation features also use Ghostscript or qpdf. See System setup.
