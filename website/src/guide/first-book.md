# Your first book

Three steps, no configuration.

## 1. Make a folder

A couple of markdown files is enough.

```
my-book/
├─ chapter-01.md
└─ chapter-02.md
```

## 2. Open it in Gutterpress

Click **Open Folder**. A paginated preview updates live as you edit.

## 3. Save PDF

Done. Ready for a printer, a print-on-demand service, or publishing straight to Google Drive.

## Or from the command line

The `gutterpress` CLI builds the same PDF in scripts and CI:

```
gutterpress build ./my-book
```
