Extensions

Find plugins

Every plugin a book can add. Five are built into Gutterpress and need no network. On npm, a Gutterpress extension is tagged gutterpress, and any markdown-it plugin tagged markdown-it-plugin works unchanged: this page runs the same search as the desktop app's Features tab. Click a plugin for the command that adds it to a book. The plugins chapter covers installing, ordering and writing your own.
