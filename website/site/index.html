Markdown & CSS, typeset for print

Write it in Markdown. Print it for real.

Gutterpress turns a folder of markdown files into a professionally typeset PDF: the kind you send to an offset printer or a print-on-demand service. It uses a native Chromium print engine and the W3C CSS Paged Media spec, so page breaks, running headers, columns, page numbers, and bleed are handled for you.

What it does

Print production, from a text editor

Live preview

Paginated layout: your book renders the way it will print, while you edit.

PDF export

From the app, or from the gutterpress CLI in scripts and CI.

Print-ready output

PDF/X with CMYK and an ICC profile for offset printers, PDF/A for archives.

Custom CSS for everything

Typography, page size, margins, columns, running headers and footers, page numbers, bleed.

Plugins

Use any of hundreds of markdown-it plugins for custom markdown, or write your own.

Validation

Before and after a build: image DPI, color space, font embedding, structural PDF checks.

Publishing

To itch.io, DriveThruRPG, Amazon KDP, Azure Static Web Apps, Shopify, and Google Drive.
