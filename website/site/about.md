# About

Gutterpress was born in [Dimm City](https://dimm.city), a tabletop roleplaying game.
Dimm City's books are long, dense and heavily designed: skill cards, specialty pages,
stat blocks, learning paths and chapter openers, all bound for print-on-demand. Gutterpress
is the tool that was built to write and lay them out in markdown and CSS, and to turn them
into print-ready PDFs.

## Built for one game, open to every book

The Dimm City books are still set in Gutterpress. The Dimm City field guide is one of the
books its preview and print output are checked against, and its look is an ordinary
Gutterpress extension:
[gp-dimm-city](https://github.com/dimm-city/gp-dimm-city), the markdown-it macros, print
stylesheets, design tokens, fonts and page templates the Dimm City books are set in.
Install it into a book with:

```
gutterpress ext add gp-dimm-city ./my-book
```

Nothing in Gutterpress itself is specific to the game. What a game needs (its components,
its page templates, its brand) lives in an extension like that one, so the same tool works
for a novel, a manual, a zine or a rulebook of your own. You can
[find more extensions](/plugins.html) or [write one](/docs/plugins.html).

This site wears Dimm City's colours too: its riso black and crimson come from the game's
palette.

## Open source

Gutterpress is a desktop app, a CLI and a set of publishing tools. It is open source,
developed in the open at [github.com/dimm-city/gutterpress](https://github.com/dimm-city/gutterpress), and issues,
ideas and pull requests are welcome.
